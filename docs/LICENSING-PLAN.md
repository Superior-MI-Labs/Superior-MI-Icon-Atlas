# Visual Atlas licensing policy (not blanket relicensing)

**For new original works owned or controlled by Superior MI Labs that pass rights review**, the recommended artwork designation is **Creative Commons CC0 1.0 Universal** (public-domain dedication, with fallback license in jurisdictions where applicable). CC0 permits modification, redistribution, private or commercial use without mandatory attribution. Voluntary credit helps others find the catalog; we appreciate it but do not impose it as a condition of CC0 artwork.

Existing Icon Atlas candidate art, even when visually tagged, has `rights_reviewed: false` in original source records. The repository's current `LICENSE` is Apache-2.0. **Do not claim all existing art is CC0** until the owner, provenance and rights status have been reviewed and individual files are marked accordingly. We can change the license prospectively for new works and later relicense qualifying legacy assets explicitly after rights verification.

Code: existing repository remains Apache-2.0 unless a separate intentional copyright-holder decision changes it. Use of Apache-2.0 code does not generally require an in-app credit badge, but distributions must comply with copyright, license and any relevant NOTICE retention rules. Third-party JSZip is MIT and redistributions of its code must preserve the included MIT notice.

User imports: the file owner controls their own materials; uploading a ZIP into the local browser does not grant Superior MI Labs publication rights. The builder preserves source license IDs in exports and marks unspecified source rights as unspecified. If the user wants a pack published, require an explicit contribution and an appropriate rights declaration.

CC0 does not waive others' copyright or third-party rights, and does not waive trademark or patent rights. It provides no warranty or indemnity. Brand and project marks are separate from the permissive art policy. We should seek legal review before changing the existing published collection's asserted licensing status.

References: https://creativecommons.org/publicdomain/zero/1.0/ and https://wiki.creativecommons.org/wiki/CC0_FAQ
