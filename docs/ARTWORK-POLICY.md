# Artwork release policy

- Candidate sheets do not become verified semantic icons merely by occupying a cell.
- Every icon requires a semantic naming pass; keep stable grid IDs for the review stage.
- White RGBA transparent source, optional separate solid black outline, independent tint alpha.
- Occupancy target: artwork within 4–6 px of at least one cell edge; never let strokes bleed into adjacent cells.
- Do not import Material Design or Font Awesome artwork into the clean track without explicit source/rights review.
- Approved assets can later receive canonical semantic IDs with explicit migrations/aliases; no speculative renames.
