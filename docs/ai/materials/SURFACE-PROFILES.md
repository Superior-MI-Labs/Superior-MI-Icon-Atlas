# Surface material profile candidate (v1)

Atlas remains the content authority. A material is an optional profile on an existing, addressable `region`, not a new asset kind, independent catalog or renderer. Legacy manifests remain valid. `visual_profile` is an optional shared visual descriptor and may be added to non-material assets. Neither profile grants gameplay permissions or environmental compatibility.

## Manifest contract
- `material.schema`: `smi-surface-material/1`.
- `channels.base_color: "self"`: the existing whole region's texture; the existing archive resolver and selected ZIP exporter own the dependency. Initial material regions must be whole, untrimmed, non-nine-slice and sRGB. No other channels are accepted yet. Future normal, roughness, height, metallic, AO, opacity and emissive roles require coordinated typed references, channel-space and dependency/export validation. Do not invent channel maps from color artwork.
- `role`: `surface`, `liquid_appearance`, `effect_appearance`. The last two are color-only visual appearances, not physical liquid or effect simulation.
- `repeat_intent`: two values (U,V), each repeat/clamp/mirror. This is intended sampling, not certified seamlessness.
- `suggested_coverage_m`: optional two positive dimensions. An authored suggestion, not a physical measurement. G Flow uses 2 × 2 m as an initial consumer-adjustable default; omit unknown scale rather than implying a measurement.
- `seam_screen`: optional `rgb-wrap-mae-v1` metric. Absolute opposite-edge RGB mean error (0–1) and ratio to internal adjacent-pixel mean gradient (floor 1/255) for both axes. `low-discontinuity` means both ratios <=1.5 and both absolute errors <=0.045. Otherwise `review-required`. Screening is not visual certification; repetitive motifs, alignment, baked light and perspective require real inspection. Values were computed on exact delivered JPEGs.
- `source`: optional original filename, SHA-256, source pixel dimensions, encoding and processing string. Filename is descriptive, not a path to fetch. Source bytes remain with the contributor. Texture SHA-256 is the exact distributed file digest.
- `associations`: optional environments and conditions; semantic hints rather than measured suitability, weather behavior or physics. Existing asset `tags`, `subjects`, `aliases`, `style` and classification remain canonical descriptive metadata. No duplicate per-asset relationship table.
- `visual_profile.schema`: `smi-visual-profile/1`; `palette` contains 1–16 sRGB hex colors and integer `weight_bp` (basis points summing to 10000); no duplicate hex; `palette_method` identifies the extraction method; `color_names` are coarse, measured-derived search hints. G Flow uses deterministic 128-pixel median-cut sampling. No color profile is required on older assets.

## Discovery and runtime
The existing build projects both optional profiles into `public-catalog.json` and adds the derived capability `surface-material`. The existing taxonomy and thumbnails display all materials. The public inspector shows color swatches and a 2 × 2 repeat of the actual region, without modifying the ordinary preview/PNG download. The same selected ZIP export preserves the profiles; base color is `self`, so no extra dependency resolver is required.

Use `VisualAtlasCollections.rankRelated(source, candidates, options)` for optional deterministic discovery. `categoryPrefixes` and `requiredRole` are hard filters; weights (`semantic`, `color`, `style`) and `limit` are explicit. Keyword overlap excludes generic descriptors and color names, weighted palette distance uses OKLab, missing color is reported as null, and scores do not represent probabilities or verified compatibility. Recommendations are recalculated from current catalog content; no semantic match is automatically fetched or substituted. A deliberate color-only query sets semantic weight to zero. Existing typed concept relationships and mandatory dependency graphs are unaffected.

Worlds should filter by `capabilities` / `material.role`, take the asset ID and exact parent pack's archive digest/immutable locator from the same public catalog, use the shared upstream exact runtime resolver, and locate that region and texture. No duplicate ZIP reader or world-owned material registry. Projection, painting, blending, collision, physical substrate, instance state and scatter are host responsibilities. No terrain changes accompany this release.

## G Flow preview qualification
302 source images, each 1024 × 1024 RGB JPEG, grouped into 15 bounded packs. Re-encoded quality 90, 4:2:0 without resizing or geometric edits. These are color artwork only: baked illumination and relief may be present. Do not mark real PBR, host-qualified, calibrated, or artist-reviewed. The catalog visual status is `pending`. Rights must be confirmed by the uploader before the CC0 allowlist entry is created. Preserve the original archive and all stable IDs in future revisions. Existing retention budget and full regression/browser gates still apply.
