# Independent AI authoring benchmark (protocol, not results)

Freeze the Atlas commit, the public handoff and tool-access category before each comparison. Use fresh conversations, the same request and reference materials, a fixed correction budget and identical validation environment. Do not feed previous successful outputs or hidden acceptance answers to a candidate. Record model/version, access, attempts, time and user interventions; use an unknown value rather than inventing cost or timing.

| Task | Fixed deliverable | Evaluation focus |
|---|---|---|
| Icons | 24 original matching sci-fi symbols, transparent, individually named | semantic accuracy, crop cleanliness, consistency |
| Meter | layered 0–100 health meter, two fill presets, visible low-end values | numeric fidelity and raw outputs |
| Inventory | independently configurable six-slot equipment panel | reusable state families, input isolation |
| Effect | looping transparent scanning overlay | frame timing, seam, crop alignment |
| Character | reference-locked idle and walk qualification slice | identity, pose/motion, stable pivots |
| HUD | health/energy, cooldowns, inventory and navigation | dependency reuse, complete ZIP, working preview |

Prepare creator-specific acceptance specs and browser scenarios before generation; include negative checks and expected invariant pixels where relevant. Use the same official acceptance command on every exact candidate. Record first-pass structural and scenario outcomes separately from manual semantic and style review (blind reviewers where practical). Report covered scenarios, omissions and disagreements; a partial result is not full qualification. Repeat with different subjects/styles to detect overfitting. Do not publish benchmark artwork without authorization.

No cross-model results are claimed yet.
