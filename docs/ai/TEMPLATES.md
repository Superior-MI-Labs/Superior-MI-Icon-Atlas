# Templates and starter assets

- [Sprite sheet reference grids: choose and download individual PNGs](../templates/sprite-grids/index.html) · [All reference grids ZIP](../templates/sprite-grid-references.zip). Transparent interiors, thin gray lines, exact square cell pitches, multiple aspect ratios. Use as visual layout references for image generation, according to the [source artwork workflow](IMAGE-ENGINE-WORKFLOW.md). The existing site build generates these files from the canonical layout definitions in `tools/sprite_grids.py`.
- [Blank authoring grids](../templates/authoring-grids.zip) remain available as exact packing destinations. Generated artwork must still be inspected, measured and repacked independently.
