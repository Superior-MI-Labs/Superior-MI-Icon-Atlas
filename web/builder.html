Free use and contributions

We aim to offer original, rights-cleared artwork under CC0 1.0, which does not require attribution and permits commercial use. Existing candidate assets still require individual rights review, and the current repository code is Apache-2.0. Check the license attached to each asset. Credit is appreciated, not a condition for CC0 artwork.

For original packs you'd like added publicly, contribute through GitHub pull requests. Local imports are never automatically published.
