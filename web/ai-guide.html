Make a private asset pack with any AI assistant

Copy the instructions below, paste them into your assistant, and describe the animation, icon, GUI control, banner, or texture pack you want. When your assistant produces a ZIP, import it into Visual Atlas Builder. The files stay in your browser; they are not submitted to Superior MI Labs.

Create a self-contained Superior MI Visual Atlas pack ZIP for my requested visual asset.

Read the format and example fixtures here:
https://superior-mi-labs.github.io/Superior-MI-Icon-Atlas/schemas/smi-visual-pack-v1.schema.json
Example manifests:
https://github.com/Superior-MI-Labs/Superior-MI-Icon-Atlas/tree/design/visual-atlas-r0/proposals/visual-atlas-r0

Required ZIP contents:
- manifest.json using schema "smi-visual-pack/1", with pack_id, version, textures, assets.
- All referenced local texture PNG/WebP files inside textures/.
- Clear, descriptive names, tags, subjects, and accurate pixel rectangles.
- A license/provenance declaration for artwork you have rights to use.

Supported asset kinds:
- region: id, kind, texture ID, rect_px [x,y,w,h], optional nine_slice_px [left,top,right,bottom].
- sequence: id, kind, frames [{asset, optional duration_ms}], default_fps, playback (once/loop/pingpong).
- composition: id, kind, size_px [w,h], layers [{id,asset,optional offset_px,opacity,visible_when,clip,state_from_input,position_from_input}], optional typed inputs, optional duration_ms, playback and layer keyframe tracks.
- state_set: id, kind, states {name:assetId}, default_state.

Keyframes: composition layers may use tracks [{property:"x|y|opacity|scale_x|scale_y|rotation_deg",keyframes:[{time_ms:0,value:0,easing:"linear|smooth|step"},...]}]. Keyframes must have strictly increasing times. Composition duration_ms can bound the animation, and playback can be once, loop or pingpong. The builder can author these tracks visually and export rendered PNG frame ZIPs.

Use a single stable ID per asset, real images and honest metadata. All references must resolve. Avoid embedded scripts, remote image URLs, path traversal, and proprietary third-party graphics without permission. Do not assume 24x8 cells; use exact image bounds.

Validate the ZIP, file names, dependencies, texture dimensions, state names, and frame durations. Give me a ready-to-import ZIP. Explain which features are working versus merely conceptual.

Examples you can request: “A cracked-glass component with clean / scratched / shattered states and an optional looping rain layer”; “A health bar with an animated glint and adjustable fill”; “A 5-frame hovering shield icon with a togglable notification badge”; “A 4-state scalable GUI button pack”; “A looping animated website banner.”

Important compatibility notes

The initial builder supports local images, zipped smi-visual-pack/1 manifests, per-frame sequencing, state sets, layers, basic parameter binding, nine-slice, and ZIP export. It supports basic property keyframes and a timeline editor; it is not a production animation suite, shader composer, or game engine. Include all required textures in the ZIP. For private imports, the site does not need an account or server upload.

python3 tools/build_site.py
python3 -m http.server 8000 --directory site
