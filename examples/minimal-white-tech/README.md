# Minimal White Tech 1.0

Four-wave sci-fi HUD collection: 362 assets (280 regions, 60 compositions, 17 state sets and 5 sequences) in four original transparent texture atlases. Default: White Tech Command HUD. Import the self-contained ZIP in the Visual Atlas Builder. Host owns text, maps, telemetry, game rules and formatted digit states; no new runtime is required.
